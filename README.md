# Victorious Innovatech Solutions

> Official Website & Digital Agency Platform for Victorious Innovatech Solutions. Custom Web Design, Modern Development, Mobile Solutions, and Backend Systems.

## 🚀 Features
- **Frontend:** Astro + React with Tailwind CSS & Framer Motion
- **Modern UI:** Responsive, dynamic animations, dark/light aesthetics
- **Interactive Pages:** Services, Portfolio Showcase, Team, Experience, and Contact
- **Backend APIs:** PHP endpoints for inquiries, automated mailers, contact messages, and newsletters
- **AI Integration:** Interactive Chat Assistant powered by Google Gemini

## 🛠️ Local Development

### Prerequisites
- Node.js (v18+)
- PHP (v8+)

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/yuvi881088/victorious-innovatech-solutions.git
   cd victorious-innovatech-solutions
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
